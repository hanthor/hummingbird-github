# Contributing

Add source RPM names—not binary RPM names—to `config/bootstrap-packages.txt`.
Keep additions dependency-first. Pull requests validate configuration but cannot
publish packages, pages content, attestations, or image tags.

To bring in an upstream source, use **Actions → Import Rawhide package**. It
imports Fedora dist-git rather than a binary RPM, records the exact Rawhide
commit, and proposes the result through a pull request. Do not modify
`.hummingbird-upstream.json`; re-import when upstream changes.

## Running Python Tools Locally

### Prerequisites

All tools require Python 3.11+ and several system packages:

```bash
sudo dnf install python3 python-devel rpmdevtools dnf-utils git
```

For local development, install the repository:

```bash
git clone https://github.com/hanthor/hummingbird-github.git
cd hummingbird-github
```

### Validation

Validate the entire package configuration before making changes:

```bash
python3 tools/validate.py
```

This checks:
- `config/bootstrap-packages.txt` for duplicates and invalid names
- `.hummingbird-upstream.json` for required provenance fields
- Ensures at least one package is configured

### Configuration Files

#### `config/bootstrap-packages.txt`

Source RPM names, one per line. Comments start with `#`. Example:

```
# Core libraries
lib-xyz
lib-abc

# Applications
some-app
```

Keep entries **dependency-first**: list build requirements before packages that use them.

#### `packages/<name>/.hummingbird-upstream.json`

Records immutable import metadata, auto-generated by `import_rawhide.py`. Do not edit manually. Contains:

```json
{
  "package": "package-name",
  "branch": "rawhide",
  "remote": "https://src.fedoraproject.org/rpms/package-name.git",
  "commit": "<commit-sha>",
  "tree": "<tree-sha>",
  "imported_at": "2024-01-01T00:00:00Z"
}
```

### Tool Reference

#### `validate.py`

Validates package-factory configuration.

```bash
python3 tools/validate.py
```

Checks bootstrap package names and `.hummingbird-upstream.json` provenance. Exits non-zero if validation fails.

#### `import_rawhide.py`

Imports a Fedora dist-git Rawhide snapshot into `packages/<name>/`.

```bash
python3 tools/import_rawhide.py <package> [--branch <branch>] [--destination <path>]
```

Arguments:
- `<package>` - Fedora dist-git source package name (e.g., `glib2`)
- `--branch` - Git branch to import (default: `rawhide`)
- `--destination` - Where to place packages (default: `packages/`)

Creates `packages/<package>/` with spec file, patches, and `.hummingbird-upstream.json`.
Records the exact commit and tree SHAs for reproducibility.

#### `import_bluefin_rawhide.py`

Resolves Bluefin binary packages and imports their Fedora Rawhide dist-git sources.

```bash
python3 tools/import_bluefin_rawhide.py <config-file> [--destination <path>]
```

Arguments:
- `<config-file>` - TOML file listing Bluefin binary packages
- `--destination` - Where to place imported packages (default: `packages/`)

Uses `dnf repoquery` to resolve binary package → source package mapping.
Fails if any binary package cannot be resolved.

#### `bootstrap_upstream_sources.py`

Creates direct-source candidates from imported RPM recipes.

```bash
python3 tools/bootstrap_upstream_sources.py [--output <file>] [config.json]
```

Arguments:
- `config.json` - Package source configuration (default: stdin)
- `--output` - Write candidates to file (default: stdout)

Reads spec files from `packages/<name>/` and resolves Source0 URLs. Outputs candidates only when:
- Source0 is an upstream HTTP(S) URL
- The URL is reachable and downloadable
- The source is not from Fedora's lookaside cache

Rejects Fedora-hosted sources and reports them for explicit maintainer review.

#### `source_pipeline.py`

Fetches and verifies direct-upstream sources, failing closed on any mismatch.

```bash
python3 tools/source_pipeline.py [--config <file>] [--output <dir>]
```

Arguments:
- `--config` - JSON file with source specifications (default: `config/upstream-sources.json`)
- `--output` - Directory to cache downloaded sources (default: current directory)

Configuration schema:

```json
[
  {
    "name": "package-name",
    "url": "https://upstream.org/package-1.0.tar.gz",
    "sha512": "<hash>",
    "sha256_url": "https://upstream.org/checksums.txt",
    "gpg_key_url": "https://upstream.org/signing-key.gpg"
  }
]
```

Required fields: `name`, `url`, `sha512`. Optional: `sha256_url`, `gpg_key_url`.

Fails immediately if checksums don't match or signatures don't verify.

#### `recalculate_hummingbird_gaps.py`

Measures Bluefin's package contract against a Hummingbird image and repository.

```bash
python3 tools/recalculate_hummingbird_gaps.py \
  --manifest <toml> \
  --image-packages <file> \
  --repo-packages <file> \
  --image <image-ref> \
  [--output <file>]
```

Arguments:
- `--manifest` - Bluefin package contract (TOML, default: `config/bluefin-packages.toml`)
- `--image-packages` - File with image-installed package names (one per line)
- `--repo-packages` - File with factory-published package names (one per line)
- `--image` - Container image reference for observability
- `--output` - Report destination (default: `reports/hummingbird-gap.json`)

Outputs a report distinguishing:
- Packages already in the base image
- Packages newly available from the factory
- Gaps not yet available

#### `scan_rawhide_state.py`

Creates a deterministic Rawhide availability report (observability only).

```bash
python3 tools/scan_rawhide_state.py [--manifest <toml>] [--output <file>]
```

Arguments:
- `--manifest` - Package list (TOML, default: `config/bluefin-packages.toml`)
- `--output` - Report destination (default: stdout)

Queries current Rawhide for each package using `dnf repoquery`. Reports are for observability;
Rawhide metadata must not trigger package updates. Package updates are gated by `dist_git.py` (Koji).

#### `dist_git.py`

Koji-gated Fedora dist-git snapshot checker.

```bash
python3 tools/dist_git.py [--manifest <toml>] [--output <file>]
```

Arguments:
- `--manifest` - Package list (TOML, default: `config/bluefin-packages.toml`)
- `--output` - Candidates output (default: stdout)

Verifies each Rawhide snapshot against Koji: a dist-git commit is a candidate only if Koji
reports the same NVR (name-version-release) as a completed build. Prevents promoting packages
solely because dist-git advanced without a corresponding build.
